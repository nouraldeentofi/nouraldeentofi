I build AI automations that turn messy manual work into self-running workflows, and the React interfaces people use on top of them.

My edge is **Arabic-first document AI**: n8n + LLM pipelines that read Arabic and English invoices, receipts, CVs and business cards, validate them, and push clean data into sheets, CRMs and dashboards.

Day to day I'm the **Technical Lead at DFS** in Al Khobar: I lead the engineering team and own the frontend hands-on, from planning and estimates to code review and release. I build with **Claude Code** every day.

Al Khobar, Saudi Arabia. Arabic and English.

### Building right now

- **A second CRM** — the company platform I built at DFS led a second company to ask our team for its own custom CRM. React + TypeScript, Arabic/English, I lead the frontend and delivery
- **Nour Motion Studio** — a motion-graphics video maker I built with Claude Code. It renders MP4 in your browser: no server, no API key
- **Claude as a manager** — a local Qwen 35B model writes code on my laptop, Claude plans and reviews it
